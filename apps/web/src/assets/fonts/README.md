# Tipografías públicas locales

Familias de la referencia Stitch App Sorteos Luxury Platform. Descargadas de
Google Fonts el 2026-11-07; servidas mediante `next/font/local` únicamente en
el layout público. Archivos variables, sin peticiones a Google en el navegador
ni durante el build.

- [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay):
  normal y cursiva, pesos 400–900. Licencia `OFL-Playfair-Display.txt`.
- [Plus Jakarta Sans](https://github.com/google/fonts/tree/main/ofl/plusjakartasans):
  normal, pesos 200–800. Licencia `OFL-Plus-Jakarta-Sans.txt`.
